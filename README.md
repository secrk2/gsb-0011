# 矫务通 · 社区矫正管理系统

区司法局自研社区矫正管理系统「矫务通」。本仓库落地骨架与三个核心模块：

- **矫务作战台**：各司法所在矫漏斗、今日应报到、越界与违规红点
- **对象档案**：六态状态机、姓名脱敏与二次确认留痕、对象间数据隔离
- **定位监控**：腕表 5 秒回传 GPS+设备状态，实时轨迹、多边形电子围栏（活动范围/禁区）、
  GPS 漂移过滤、按司法所时区的禁行日判定、周/月视图、落点越界人工标记留痕、在矫完成度双口径

技术栈：Spring Boot 3.3（Java 17）+ Spring Data JPA + H2 + JWT；前端零依赖原生静态页面（含原生 SVG 地图）；Nginx 反代；Docker Compose 一键拉起。

## 一键启动

```bash
docker compose up -d --build
```

| 入口 | 地址 | 说明 |
|---|---|---|
| 前端（Nginx） | http://localhost:8104 | 管理端 + 对象手机端，同源反代 API |
| 后端直连 | http://localhost:7104 | Spring Boot，健康检查 `/api/health` |

前端容器会等后端健康检查通过后再启动。数据持久化在 Docker 卷 `jiaowutong-data`（H2 文件库），重启不丢数据；要恢复出厂种子数据：

```bash
docker compose down -v && docker compose up -d --build
```

## 核心业务规则

### 1. 档案状态机（非法回退拦截 + 原因说明）

```
入矫登记 ──→ 在矫 ──→ 请假外出 ──→ 在矫（销假）
              │  └──→ 训诫 ──→ 在矫（教育恢复）
              │        └──→ 收监（终态）
              ├──→ 收监（终态）
              └──→ 解除（终态）
请假外出 ──→ 训诫（逾假不归）
```

- 终态（收监/解除）不可回退；入矫登记不可回流；不允许跨状态跳跃
- 非法操作返回 `409 INVALID_TRANSITION`，消息说明**原因和当前允许的下一状态**，前端弹窗原样展示
- 每次流转写 `status_transition` 留痕（操作人、理由、时间），训诫同时生成违规红点

### 2. 姓名脱敏与二次确认留痕

- 列表/接口默认只返回脱敏名：**姓氏拼音首字母-矫正编号**（如 张伟国 → `Z-JWT26001`），`fullName` 字段不下发
- 查看全名必须二次确认弹窗 + **填写不少于 4 字的工作理由**
- 每次查看落 `name_view_audit`（查看人、理由、时间），档案页可回看全部留痕
- 矫正对象本人查看自己档案显示真名；看不到任何他人数据

### 3. 对象隔离 / 越权错误态

- 矫正对象：仅能访问本人档案；干警：仅本能访问本所对象；监管员：全区
- 越权访问（如对象 A 改 URL 访问对象 B）返回 **403 错误页**（说明原因），不是空白页或列表页
- 后端在 Service 层强制数据范围，不依赖前端隐藏

### 4. 乡村断网：离线定位、防旧位置、合并幂等

对象手机端（`obj4` 登录后进入“我的矫正”）：

- **离线提示**：断网时黄色横幅提示“本地缓存中（N 点）”，恢复后绿色提示并自动补传；可点「模拟断网」在无真机情况下演示
- **不能用旧位置糊弄**：每个定位点带 GPS 采集时间（`pointTime`），服务端按时钟强校验
  - 实时点采集时间超过 **5 分钟** → `422 STALE_LOCATION` 拒绝（报到和轨迹都一样）
  - 离线补传点超过 **72 小时**窗口 → 拒绝；未来时间 → 拒绝
  - 页面上「🧪 尝试用 2 小时前缓存旧定位报到」可直接验证
- **恢复后合并**：批量点按**采集时间**合并入轨迹，对象最新位置取采集时间最大者，乱序/迟到的历史点不会把当前位置冲回旧位置
- **幂等不重复**：手机为每个点生成 `clientPointId`（UUID），库内唯一约束；断网期间重复重放只计入 `duplicates`，**不产生重复轨迹点**（含曾被漂移丢弃的点，重放也不复活）
- **GPS 漂移过滤（不只比距离）**：新点与最近一个采信点之间，位移 >100m 噪声地板且等效速度 >200 km/h 判 `DRIFT_DROPPED`——同样 50km 跳变，隔 5 秒是漂移（丢弃），隔 2 小时离线补传是正常移动（采信）；丢弃点不连线、不判越界、不推进锚点（连续跳点不会把基准点带飞），但留底可查
- **多边形电子围栏**：禁区（FORBIDDEN）优先级最高，进入即越界；否则须落在任一活动范围（ALLOW）多边形内；未配置多边形时回退司法所圆形围栏
- 越界仅在无未处置同类型红点时报警一次（普通越界 / 禁行日越界 / 设备关机无信号 / 人工标记分类），批量补传历史点不刷屏

### 5. 作战台

- 顶部 4 个指标：监外执行中、建档总数、今日应报到、未处置红点
- 全区漏斗：入矫登记/在矫/请假外出/训诫/收监/解除（在矫口径 = 在矫+请假+训诫）
- 各司法所分段漏斗条（悬停看各状态人数）+ 完整图例（颜色不单独承载语义）
- 今日应报到：已报到 / 待报到 / 逾时未报（18:00 后）
- 红点：越界 / 未报到 / 训诫，点击直达档案
- 响应式适配三档：**1440 桌面**（侧栏+双列）、**1024 平板**（图标侧栏）、**390 手机**（底部导航、表格转卡片）

### 6. 定位监控（管理端「🛰️ 定位监控」菜单，仅干警/监管员）

- **时间口径（最关键）**：库内轨迹/报到/标记/清除时间一律存 **UTC**；客户端上报带时区偏移的绝对时刻（`2026-09-18T14:00:00+08:00` / `Z`）；界面展示与“今天 / 星期几 / 是否同一天禁行”一律按**司法所配置的 IANA 时区**（`zone_id`）经 `ZoneId` 换算，夏令时由 JVM tzdata 自动处理（已用柏林冬/夏令时用例验证），不做任何手工 +8/-8。跨司法所对象各按各所时区判日界，干警不会因日界错算白跑
- **多边形围栏可视化**：SVG 实时画活动范围（绿虚线框）/ 禁区（红虚线框）、采信轨迹连线、离线补传方点、**GPS 漂移丢弃点（灰 ✕，附速度原因）**、人工标记（🚩）、当前位置脉冲点；回退圆围栏一并画出
- **实时**：总览与状态卡每 **5 秒**轮询（轻量心跳只刷当前点，不重画整图）；轨迹线每 15 秒静默重拉
- **周 / 月两视图**：窗口先按司法所本地日界定（自然周周一 00:00 / 自然月 1 日 00:00）再换算成 UTC 查询；月视图服务端等间隔抽稀（≤900 点，越界点全保留）
- **落点标记越界（二次确认留痕）**：点击图上越界落点 → 必填 ≥4 字原因 → **服务端独立复核该点确在活动范围外/禁区内**才采信（`MARK_INSIDE` 复核失败会拒绝，围栏内点造不出假红点）；漂移点不可信、禁止标记（`MARK_DRIFT`）；同点不可重复标记；生成红点并写 `location_mark`（操作人/原因/UTC 时间/复核结论）
- **三种空态/错误态分开，绝不笼统“暂无数据”**：
  - 加载失败 → 错误态（⚠️ + 原因 + 重试）；
  - 该对象无轨迹（从未收到回传）→ 📭 并提示排查设备/绑定/信号；
  - 轨迹全清除 → 🧹 展示清除留痕（操作人、原因、时间、点数）；
  - 另有“有轨迹但本周/本月窗口无落点”的第四种提示，引导切视图
- **在矫完成度（你定的口径，两口径并列写在界面上）**：
  - 口径①**已打卡天数**＝矫正期内报到的不重复天数 ÷ 已过天数；
  - 口径②**已完成关键报到**＝规定报到星期当天实到次数 ÷ 到期应到次数；
  - 只在非规定日零散报到的对象，口径①可能不低但口径②为 0，界面黄底标出「两口径背离」并注明“处置以口径②为准”
- **设备状态**：随腕表回传 `NORMAL / LOW_BATTERY / NO_SIGNAL / POWER_OFF` 与电量；关机/无信号边沿生成设备异常红点；最近回传超 5 分钟置「长时间无回传」
- 种子覆盖：陈大山（禁行日进入乡北矿区禁区 + 1 个漂移跳点 + 低电）、周文斌（双口径背离）、吴桂芳（轨迹已清除留痕）、孙满堂（从未上报）、徐建华（腕表关机告警）

## 目录结构

```
├── docker-compose.yml          # backend(7104) + frontend(8104)
├── backend/
│   ├── Dockerfile              # 多阶段：Maven 构建 → JRE 运行
│   ├── pom.xml
│   └── src/main/java/cn/sfj/jiaowutong/
│       ├── domain/             # 实体：对象/司法所(时区/禁行日)/轨迹点/围栏分区/标记/清除留痕等
│       ├── repo/               # JPA 仓储
│       ├── security/           # JWT、PBKDF2、鉴权拦截器
│       ├── common/time/        # TimeZones：UTC 存储 + 按司法所时区(含 DST)换算
│       ├── service/            # 状态机/脱敏/作战台/轨迹幂等漂移/围栏几何/定位监控/访问控制
│       ├── web/                # 控制器 + dto + vo
│       └── config/DataInitializer.java  # 种子数据（围栏多边形/禁区/漂移点/双口径/三态）
└── frontend/
    ├── Dockerfile              # nginx:alpine + 静态资源
    ├── nginx.conf              # SPA 回退 + /api 反代 backend:7104
    └── html/
        ├── index.html
        └── assets/             # 零依赖原生 JS/CSS（原生 SVG 地图，无地图 SDK）
            ├── api.js  ui.js  offline-queue.js  app.js
            └── views/          # login/dashboard/objects/detail/monitor/offender
```

## 本地开发（不用 Docker）

```bash
cd backend
mvn spring-boot:run            # 需要本机 JDK 17+；默认 H2 内存库
# 前端静态托管任选其一：
cd frontend/html && python3 -m http.server 8104   # 此时 API 直连 7104（已开 CORS），需把 api.js 前缀改为绝对地址
```

## 主要 API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/auth/login` | 登录换 JWT |
| GET | `/api/dashboard` | 作战台聚合（按角色裁剪数据范围） |
| GET | `/api/objects?status=&officeId=` | 档案列表（脱敏） |
| GET | `/api/objects/{id}` | 档案详情（越权 403 错误态） |
| POST | `/api/objects/{id}/transition` | 状态流转（非法回退 409 + 原因） |
| POST | `/api/objects/{id}/reveal-name` | 二次确认 + 理由 → 返回全名并留痕 |
| GET | `/api/objects/{id}/name-audits` | 全名查看留痕 |
| GET | `/api/objects/{id}/tracks` | 轨迹点（采信 + 漂移丢弃，均带 UTC/本地时间） |
| POST | `/api/offender/tracks` | 腕表批量上报（带偏移时刻；幂等/合并/时效/GPS 漂移/设备状态/多边形越界） |
| POST | `/api/offender/check-in` | 日常报到（定位时效 + 多边形围栏） |
| GET | `/api/monitor/overview` | 定位监控总览（5s 轮询；定位/设备/禁行日/三态/双口径，按角色裁剪） |
| GET | `/api/monitor/{id}?range=WEEK\|MONTH` | 单对象监控（时区窗口/围栏/抽稀轨迹/漂移点/标记/完成度） |
| GET | `/api/monitor/live/{id}` | 5s 实时心跳（仅当前状态） |
| POST | `/api/monitor/{id}/mark-breach` | 落点标记越界（二次确认原因；服务端复核 `MARK_INSIDE`/`MARK_DRIFT`） |
| POST | `/api/monitor/{id}/clear-tracks` | 清除轨迹（二次确认原因，写清除留痕） |
