# 矫务通 · 社区矫正管理系统

区司法局自研社区矫正管理系统「矫务通」。本仓库落地骨架与三个核心模块：

- **矫务作战台**：各司法所在矫漏斗、今日应报到、越界与违规红点
- **对象档案**：六态状态机、姓名脱敏与二次确认留痕、对象间数据隔离
- **定位监控**：腕表每 5 秒回传 GPS/设备状态，实时轨迹、多边形电子围栏（活动范围/禁区）、周月视图、越界落点二次核实、在矫完成度双口径

技术栈：Spring Boot 3.3（Java 17）+ Spring Data JPA + H2 + JWT；前端零依赖原生静态页面（自绘 SVG 地图）；Nginx 反代；Docker Compose 一键拉起。

## 一键启动

```bash
docker compose up -d --build
```

| 入口 | 地址 | 说明 |
|---|---|---|
| 前端（Nginx） | http://localhost:8104 | 管理端 + 对象手机端，同源反代 API |
| 后端直连 | http://localhost:7104 | Spring Boot，健康检查 `/api/health` |

前端容器会等后端健康检查通过后再启动。数据持久化在 Docker 卷 `jiaowutong-data`（H2 文件库），重启不丢数据；要恢复出厂种子数据：

```bash
docker compose down -v && docker compose up -d --build
```

## 核心业务规则

### 1. 档案状态机（非法回退拦截 + 原因说明）

```
入矫登记 ──→ 在矫 ──→ 请假外出 ──→ 在矫（销假）
              │  └──→ 训诫 ──→ 在矫（教育恢复）
              │        └──→ 收监（终态）
              ├──→ 收监（终态）
              └──→ 解除（终态）
请假外出 ──→ 训诫（逾假不归）
```

- 终态（收监/解除）不可回退；入矫登记不可回流；不允许跨状态跳跃
- 非法操作返回 `409 INVALID_TRANSITION`，消息说明**原因和当前允许的下一状态**，前端弹窗原样展示
- 每次流转写 `status_transition` 留痕（操作人、理由、时间），训诫同时生成违规红点

### 2. 姓名脱敏与二次确认留痕

- 列表/接口默认只返回脱敏名：**姓氏拼音首字母-矫正编号**（如 张伟国 → `Z-JWT26001`），`fullName` 字段不下发
- 查看全名必须二次确认弹窗 + **填写不少于 4 字的工作理由**
- 每次查看落 `name_view_audit`（查看人、理由、时间），档案页可回看全部留痕
- 矫正对象本人查看自己档案显示真名；看不到任何他人数据

### 3. 对象隔离 / 越权错误态

- 矫正对象：仅能访问本人档案；干警：仅本能访问本所对象；监管员：全区
- 越权访问（如对象 A 改 URL 访问对象 B）返回 **403 错误页**（说明原因），不是空白页或列表页
- 后端在 Service 层强制数据范围，不依赖前端隐藏

### 4. 乡村断网：离线定位、防旧位置、合并幂等

对象手机端（`obj4` 登录后进入“我的矫正”）：

- **离线提示**：断网时黄色横幅提示“本地缓存中（N 点）”，恢复后绿色提示并自动补传；可点「模拟断网」在无真机情况下演示
- **不能用旧位置糊弄**：每个定位点带 GPS 采集时间（`pointTime`），服务端按时钟强校验
  - 实时点采集时间超过 **5 分钟** → `422 STALE_LOCATION` 拒绝（报到和轨迹都一样）
  - 离线补传点超过 **72 小时**窗口 → 拒绝；未来时间 → 拒绝
  - 页面上「🧪 尝试用 2 小时前缓存旧定位报到」可直接验证
- **恢复后合并**：批量点按**采集时间**合并入轨迹，对象最新位置取采集时间最大者，乱序/迟到的历史点不会把当前位置冲回旧位置
- **幂等不重复**：手机为每个点生成 `clientPointId`（UUID），库内唯一约束；断网期间重复重放只计入 `duplicates`，**不产生重复轨迹点**
- 越界按司法所电子围栏判定（多边形活动范围，未配置多边形时回退中心圆）；仅在未处置越界红点不存在时报警一次，批量补传历史越界点不刷屏

### 5. 定位监控（新增）

左侧「🛰️ 定位监控」菜单进入。腕表**每 5 秒回传一帧** GPS + 设备状态（电量/信号/是否佩戴），管理端总览与轨迹均按 5 秒实时增量刷新。

**时间与时区（跨时区不算错）**

- 所有定位/报到/事件时间一律按 **UTC 存储与传输**（`Instant`，ISO 带 `Z`），JVM 与 Jackson 默认时区固定 UTC，不随容器 `TZ` 漂移
- 司法所带 `timezone`（IANA，如 `Asia/Shanghai`、`Asia/Urumqi`）；“今天/星期几/是否禁行/是否同一天”全部先把 UTC 转到**对象所属司法所时区**再判，前端也按该时区显示——干警跨时区查看不会替对象换时区
- 禁行时段用地区名时区（非固定偏移），**夏令时切换由 tzdb 规则处理**：纽约测试用例覆盖春进（不存在的 02:30）与回拨（重复的 01:00–02:00），切换日不误报、不漏报；跨午夜时段（22:00–05:00）凌晨的点回溯“前一天起始星期”判同一次禁行

**GPS 漂移过滤（不只比距离）**

- 点按采集时间排序后逐点比对上一**可信锚点**：等效速度 > 45 m/s（约 162 km/h）且跳变 ≥ 100 m 判为漂移
- 漂移点标 `DRIFT_DISCARDED` **留痕但不连线、不移动锚点、不更新位置、不触发越界**；下一点仍以原可信点比对，避免被跳点带偏（小于 100 m 的常规抖动吸收）

**多边形围栏与禁区**

- 活动范围 ALLOW_RANGE（ray-casting 点面判定，支持凹多边形；未配多边形回退中心圆）；禁区 FORBIDDEN 多边形 + 可选按星期/跨午夜时段排程
- 几何命中且处于禁行时段才算“禁区闯入”；无排程的禁区全天禁行

**周/月两视图与落点核实**

- 周视图 7 天 / 月视图 30 天，时间窗按对象时区的当前时刻回取再转 UTC 查询；首屏抽稀（越界/禁区/离线点全保留），`since` 增量轮询不重传全量
- 地图为零依赖自绘 SVG（等距经纬度投影、围栏多边形、轨迹线、越界红点/禁区紫点、当前位置脉冲）
- 对“会越界”的落点可进入核实模式，**二次确认 + 必填原因留痕**；服务端用当前围栏几何与该所时区**重新计算**该点，把正常点误标“确认越界”会被拒绝（`POINT_NOT_ANOMALY`）

**三种空态/错误态分开（不统一“暂无数据”）**

1. 加载失败：错误态 + 原因 + 「重新加载」，说明设备仍在回传
2. 该对象无轨迹：提示腕表未激活/无有效帧（漂移点不计入轨迹）
3. 轨迹已清除：显示清除时间（对象时区）、操作人、点数、原因的留痕卡片

清除轨迹是高危操作：二次确认 + 必填原因，删除并清空实时位置，落 `monitor_action` 留痕。

**在矫完成度（口径写在界面上）**

- 近 30 天双口径并列，定义直接上墙：**口径一·打卡天数** = 实际有报到天数 ÷ 30（非报到日额外打卡也计入）；**口径二·关键报到** = 规定报到日当天完成次数 ÷ 应到节点数（只认节点）
- 只部分报到的对象两口径可能相反（种子周文斌 60% vs 0%），此时界面显著告警，提示不能只报一个百分数

### 6. 作战台

- 顶部 4 个指标：监外执行中、建档总数、今日应报到、未处置红点
- 全区漏斗：入矫登记/在矫/请假外出/训诫/收监/解除（在矫口径 = 在矫+请假+训诫）
- 各司法所分段漏斗条（悬停看各状态人数）+ 完整图例（颜色不单独承载语义）
- 今日应报到：已报到 / 待报到 / 逾时未报（按对象所在司法所时区的当地 18:00 判定）
- 红点：越界 / 未报到 / 训诫，点击直达档案
- 响应式适配三档：**1440 桌面**（侧栏+双列）、**1024 平板**（图标侧栏）、**390 手机**（底部导航、表格转卡片）

```
            └── views/          # login/dashboard/objects/detail/monitor/offender
```

## 本地开发（不用 Docker）

```bash
cd backend
mvn spring-boot:run            # 需要本机 JDK 17+；默认 H2 内存库
# 前端静态托管任选其一：
cd frontend/html && python3 -m http.server 8104   # 此时 API 直连 7104（已开 CORS），需把 api.js 前缀改为绝对地址
```

## 主要 API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/auth/login` | 登录换 JWT |
| GET | `/api/dashboard` | 作战台聚合（按角色裁剪数据范围） |
| GET | `/api/objects?status=&officeId=` | 档案列表（脱敏） |
| GET | `/api/objects/{id}` | 档案详情（越权 403 错误态） |
| POST | `/api/objects/{id}/transition` | 状态流转（非法回退 409 + 原因） |
| POST | `/api/objects/{id}/reveal-name` | 二次确认 + 理由 → 返回全名并留痕 |
| GET | `/api/objects/{id}/name-audits` | 全名查看留痕 |
| GET | `/api/objects/{id}/tracks` | 有效轨迹点 |
| GET | `/api/monitor/overview` | 定位监控总览（实时位置/心跳/设备状态，5s 轮询） |
| GET | `/api/monitor/objects/{id}/tracks?range=WEEK\|MONTH&since=` | 周/月轨迹（首屏抽稀，since 增量） |
| POST | `/api/monitor/objects/{id}/points/{pointId}/verify` | 越界落点二次核实（服务端重算 + 原因留痕） |
| POST | `/api/monitor/objects/{id}/clear-tracks` | 清除轨迹（必填原因留痕） |
| GET | `/api/monitor/objects/{id}/actions` | 清除/核实操作留痕 |
| POST | `/api/offender/tracks` | 腕表轨迹批量上报（UTC、幂等/合并/时效/漂移过滤/禁区判定） |
